# Voice Changer 1.0 (`voice.changer.private`)

Офлайн-приложение для изменения голоса: микрофон и гарнитура в реальном времени, режим записи, аудио/видео файлы,
озвучка текста. Без разрешения INTERNET, без сервисов Google, без AndroidX и сторонних библиотек (подойдёт для GrapheneOS).

## Возможности
- **Микрофон**: «в реальном времени» (звук сразу идёт на выбранное устройство) или «запись» (с паузой без пустых секунд,
  по «Готово» голос меняется, результат слушается/сохраняется/отправляется). Кнопка — «нажал/нажал» или «удерживать» (Настройки).
  Вокруг кнопки волны и лучи, реагирующие на громкость.
- **Файл** (любой аудио/видео формат Android), **Текст** (озвучка системным движком TTS + голос + эффекты).
- **Голоса**: ~55 готовых (Robot, Helium, Cave, Ghost, Vocoder, Backwards, …); верхняя кнопка «Голос: …» открывает окно выбора;
  свои голоса можно сохранять и удалять, готовые можно удалять и возвращать. Высота, скорость, громкость, 16 эффектов, реверс.
- **Фон**: несколько слоёв сразу (дождь, ветер, волны, шумы и свои файлы любой длины, играют целиком и зациклены),
  у каждого своя громкость; комбинации сохраняются.
- **Результат**: плеер с перемоткой (слушается сразу, без кодирования); «Поделиться» и «Сохранить как…» в WAV, M4A (AAC), FLAC, MP3, OGG (Opus).
- **Оформление**: цвета (включая цвет ссылок), фон (картинка / GIF / видео), картинка на кнопках, масштаб текста, скругление углов,
  размер кнопки записи, иконка в шапке и ярлык со своей картинкой на главном экране.
- **Расположение**: Настройки → Расположение элементов — порядок и видимость блоков на каждой вкладке, порядок вкладок.
- **Реверс**: «задом наперёд» для файлов, текста и записи; в реальном времени — ползунок «кусок» (звук идёт с задержкой, равной длине куска).
- **Язык**: Русский / English (или системный). **Журнал** в Настройках для разбора сбоев.
- Кнопка «VoiceChanger» в меню выделенного текста и в «Поделиться» (текст, аудио, видео).

## Сборка
Через GitHub Actions: `.github/workflows/build.yml` (проверки проекта → тесты ядра → сборка MP3 → debug APK → опционально подписанный релиз).
Локально: Android Studio или `gradle wrapper --gradle-version 8.7` → `./gradlew assembleDebug`.

### MP3
В Android нет MP3-кодера. `tools/build-lame.sh` скачивает LAME 3.100 и собирает `libvcmp3.so` (вместе с `native/`) для arm64-v8a, armeabi-v7a и x86_64.
В `build.yml` этот шаг встроен целиком (файлы-обёртки записываются прямо из workflow), так что для MP3 достаточно одного `build.yml`.
Шаг необязательный: если он не удался, приложение собирается без MP3, а журнал сборки приложен к запуску как артефакт `lame-log`. LAME — LGPL, подключается динамически.

## Проверки
    python3 tools/verify.py                       # манифест, ресурсы, строки на всех языках
    mkdir -p /tmp/build && javac -d /tmp/build app/src/main/java/voice/changer/app/dsp/*.java
    java -cp /tmp/build tests/DspTest.java        # звуковое ядро (FLAC сверяется через ffmpeg, если он есть)

## Почему namespace `voice.changer.app`, а applicationId `voice.changer.private`
`private` — зарезервированное слово Java, `package voice.changer.private;` не компилируется.
Исходники в пакете `voice.changer.app`, установленное приложение имеет id `voice.changer.private`.

## Озвучка текста
Своего синтезатора в приложении нет: используется системный интерфейс TextToSpeech и любой установленный офлайн-движок
(выбирается во вкладке «Текст»). Голоса, требующие сети, скрываются.

## Структура
    app/src/main/java/voice/changer/app/dsp/   чистая Java: питч, WSOLA, эффекты, пресеты, фон, рендер, WAV, FLAC (тесты)
    app/src/main/java/voice/changer/app/       Android: экраны, микрофон, сервис, TTS, декодер/кодеры, плеер
    native/                                     JNI-обёртка над LAME
    tools/                                      verify.py, build-lame.sh
